# ব্যাচ ভিডিও সাইট (Next.js + Supabase + ImgBB)

## সেটআপ
1. **Supabase**: নতুন প্রজেক্ট খুলুন → SQL Editor-এ `supabase/schema.sql` চালান।
2. **Authentication → Users → Add user**: আপনার একমাত্র অ্যাডমিন ইমেইল/পাসওয়ার্ড দিন (Auto-confirm চালু করুন)।
3. **Authentication → Sign In / Providers**: "Allow new users to sign up" **বন্ধ** করুন (না হলে যে কেউ সাইনআপ করে লিখতে পারবে)।
4. **ImgBB**: https://api.imgbb.com থেকে API key নিন।
5. `.env.example` কপি করে `.env.local` বানিয়ে মান বসান।
6. `npm install && npm run dev` → `/admin/login`।

## ডিপ্লয়
Vercel-এ রিপো ইমপোর্ট করে তিনটি এনভায়রনমেন্ট ভেরিয়েবল দিন। `IMGBB_API_KEY`-তে `NEXT_PUBLIC_` দেবেন না।

## সীমাবদ্ধতা (সৎভাবে)
- ওয়েবে ছবির স্ক্রিনশট/ডাউনলোড **১০০% আটকানো অসম্ভব** (ফোনের বাইরের ক্যামেরা, স্ক্রিন রেকর্ডার, DevTools)। এখানে রাইট-ক্লিক/ড্র্যাগ/লং-প্রেস বন্ধ, স্বচ্ছ শিল্ড, PrintScreen-এ ক্লিপবোর্ড ফাঁকা + ব্লার, ট্যাব/উইন্ডো ছাড়লে ব্লার, প্রিন্ট বন্ধ — এগুলো সাধারণ ইউজারকে আটকায়।
- ইউটিউব "suggested videos" পুরোপুরি বন্ধ করার অফিসিয়াল উপায় নেই (`rel=0` শুধু একই চ্যানেলের ভিডিও দেখায়)। তাই কাস্টম কন্ট্রোল + শিল্ড ব্যবহার করা হয়েছে এবং ভিডিও শেষের ০.৪ সেকেন্ড আগেই প্লেয়ার রিসেট করা হয়, ফলে end-screen আসে না।
- ImgBB থেকে ছবি মুছতে হলে ImgBB-র ওয়েবসাইট থেকে মুছতে হবে; অ্যাডমিন প্যানেল শুধু আপনার ডাটাবেস থেকে মোছে।
- আপলোডের আগে ছবি ব্রাউজারে JPEG-এ কম্প্রেস হয় (সর্বোচ্চ ২০০০px)।
